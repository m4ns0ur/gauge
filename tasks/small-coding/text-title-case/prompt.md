# Implement title casing

`text.TitleCase` is not implemented. Implement it so that it title-cases each
word in `s`:

- Split words on runs of whitespace.
- Uppercase the first character of each word and lowercase the remaining
  characters. Use Unicode casing (`héllo` becomes `Héllo`).
- Join the words with a single space and trim leading/trailing whitespace.
- An empty or all-whitespace string returns an empty string.

Do not change the visible tests or add dependencies.
