# Normalize whitespace

`text.NormalizeSpace` is not implemented. Implement it so that it collapses
every run of whitespace (spaces, tabs, newlines) into a single space and trims
leading and trailing whitespace.

For example, `"  a  b\t\nc  "` becomes `"a b c"`, and an empty or
all-whitespace string becomes `""`.

Do not change the visible tests or add dependencies.
